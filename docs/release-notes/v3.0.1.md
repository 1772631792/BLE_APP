# BLE Studio v3.0.1

这次只修连接：**重开 App 不用再扫描，也不会再出现「搜不到设备、只能给设备断电」**。

**下载**：下面的 `BLEStudio-v3.0.1.apk`（约 51 MB，Android 7.0 及以上）。

---

## 一、这一版解决了什么

### 1. 重进 App 搜不到设备

原因不在手机：App 上次退出时，设备端可能还认为自己连着，于是**停止广播**。扫描是靠广播发现设备的，设备不广播，自然一台都搜不到，只能给设备断电让它重启。

现在启动时会先主动释放上一次残留的连接，设备恢复广播后再连回去。

### 2. 启动自动连上次的设备

- 连过一次之后，App 会记住它的名称和地址。
- 下次打开 App，**不扫描**，直接按地址连回去（默认开启）。
- 设备页顶部会多一张「上次设备」卡片，扫描列表里有没有它都能点「连接」。

### 3. 扫描兜底

点了扫描但 8 秒一个设备都没搜到，App 会自动尝试直连上次的设备，不用你手动折腾。

---

## 二、怎么用

| 场景 | 操作 |
| --- | --- |
| 正常使用 | 什么都不用做，打开 App 会自动连上次的设备 |
| 想关掉自动连 | 设备页 → 关掉「启动自动连接」 |
| 自动连没成功 | 设备页 → 点「上次设备」卡片上的「连接」 |
| 换一台设备 | 点「扫描」，连新设备；「上次设备」会自动更新成新的这台 |
| 还是搜不到 | 确认设备已上电；点「上次设备」直连；再不行才需要给设备断电重启 |

> 只记住最后一台设备。想连第三台、第四台，仍然要在列表里扫描选择。

---

## 三、其他说明

- 连接成功后默认跳到**控件页**：设备页原来的「连上后进数据页」开关改为「连上后进控件」，默认开启。
- 其余功能与 v3.0.0 一致：滑条 A / B、搓动 `tx` / `ty` 独立通道、11 字节整包模板、设置自动保存。
- 升级直接覆盖安装即可，已保存的指令和设置不会丢。
- 已知限制：设备固件如果很久才释放旧连接，启动自动重连可能要多等十几秒；此时点「上次设备」卡片重试即可。
