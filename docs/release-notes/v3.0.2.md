# BLE Studio v3.0.2

这版只改数据页的终端：**看得清、能筛、能看原始字节**。

**下载**：下面的 `BLEStudio-v3.0.2.apk`（约 51 MB，Android 7.0 及以上）。

---

## 一、终端改了什么

### 1. 每条数据都带原始 HEX

以前文本模式只显示解码后的文本，遇到二进制数据就是一堆方块和乱码。现在每条 TX / RX 下面多一行：

```text
12:04:31  RX  Hello
               HEX  48 65 6C 6C 6F
```

- 文本模式：上面是文本，下面是原始字节；
- HEX 模式（`HEX` 按钮点亮）：上面直接就是 HEX，下面重复一遍原始值；
- READ 操作会标出来源特征值。

### 2. TX / RX 可以分别过滤

终端左上角两个小胶囊：

| 状态 | 效果 |
| --- | --- |
| `TX` 和 `RX` 都亮 | 全部显示（默认） |
| 点暗 `TX` | 只看 RX（自己发的藏起来） |
| 点暗 `RX` | 只看 TX（设备回的藏起来） |
| 都点暗 | 只剩 `ERR` / `SYS` |

`ERR` / `SYS` 不受过滤影响，出错信息不会被藏掉。

### 3. 去掉了 TX / RX 累计字节数

顶栏原来会显示 `TX 1234 B`、`RX 5678 B`，占地方又没用，已删除；现在顶栏只剩终端 / 波形切换和连接状态点。

### 4. 排版调整

- 时间列、方向列固定宽度，内容左对齐，长数据自动换行；
- 原始 HEX 用小一号的暗色字，不抢正文；
- 文本模式里的控制字符（`\x00` 之类）显示成 `.`，不再是方块。

---

## 二、其他

- 功能与 v3.0.1 一致：启动自动连上次设备、扫描兜底直连、连上后进控件页、滑条 A/B、搓动 `tx`/`ty`、11 字节整包。
- 覆盖安装即可，设置和指令不会丢。
- 复制全部现在会把 HEX 行一起复制，方便贴到聊天里排查。
