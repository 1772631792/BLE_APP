# BLE Studio v3.0.0

一个不联网、不要定位权限的 BLE 调试 + 遥控 App。装上连上就能用，协议在界面上改，换固件不用重新打包。

**下载**：下面的 `BLEStudio-v3.0.0.apk`（约 51 MB，Android 7.0 及以上）。

---

## 一、安装

1. 手机点开本页，下载 `BLEStudio-v3.0.0.apk`。
2. 点安装，系统提示「未知来源应用」时选择允许（不同品牌在「设置 → 应用 → 特殊权限 → 安装未知应用」里）。
3. 首次打开会申请**附近的设备**权限，必须允许，否则扫不到设备。

> 只支持 Android。Android 12 及以上**不需要定位权限**；Android 11 及以下系统强制要求定位权限，还要打开系统的「位置信息」开关，否则搜不到蓝牙设备。

---

## 二、上手三分钟

### 1. 连设备

- 进入「设备」页，点右上角「扫描」，等 12 秒出结果（下拉可刷新）。
- 列表按信号强弱排序，点卡片上的「连接」。
- 想稳定一点：连上后在同一页展开的「服务与特征值」里，把**可写**特征值设为 `TX`，把**可通知**特征值设为 `RX`，并打开通知开关。
- 连过一次的设备会置顶并标「上次」，下次开机点「重连」即可。

连不上？App 会自动重试 3 次，还不行就走系统级 autoConnect 兜底；连上之后断线也会自己按 1→2→3→5→8→12→18→25 秒重连，并恢复通知订阅。

### 2. 看一眼数据

- 进「数据」页，默认是终端：`TX` 是你发的，`RX` 是设备回的，`ERR` / `SYS` 是错误和系统消息。
- 底部输入框发数据，点 `HEX` 切换十六进制。
- 切到「波形」页签：设备按 **VOFA+ JustFloat** 发数据就自动出图，**一帧里几个 float 就是几条曲线**，不用配通道数。

JustFloat 一帧 = N 个小端 float32 + 4 字节帧尾 `00 00 80 7F`。两通道发 1.5 和 -2.25：

```text
00 00 C0 3F   00 00 10 C0   00 00 80 7F
```

波形页里：双指捏合缩放、单指上下拖平移、点右上角 ⊙ 一键自适应、长按图例勾选要显示的通道。

### 3. 当遥控器用

进「控件」页：

| 控件 | 怎么操作 | 发什么 |
| --- | --- | --- |
| 摇杆（左） | 按住拖动，松手回中 | `x` / `y`，-128 ~ 127 |
| 滑条 A / B（页内底部） | 拖动 | `s1` / `s2`，0 ~ 100 |
| 空白处搓动 | 在没被控件占住的**任何空白**上按住拖动 | `tx` / `ty`，-128 ~ 127，反向为负，不搓就是 0 |
| 按键 k1 ~ k6 | 短按发一次；按住 600 ms 后每 250 ms 连发；k5 默认是开关式（点一下开、再点一下关） | 默认文本 `1` ~ `6`，可改 |
| 停止 | 顶部停止键 | 摇杆回中 + 搓动归零 + 清空按键，立即发一次 |

- 点「全屏」进横屏手柄布局：k1 主键压在右下，其余键绕成弧，搓动值显示在顶部工具栏。
- 点齿轮「控件设置」可以做三件事：
  1. **改指令**：每个控件的名称、内容、是否按 HEX 发送、是否开关式，改完自动保存。
  2. **选发送模式**：独立指令（每个控件各发一条，默认）或整包（合成一个定长包，按 20/50/100/200 ms 周期发）。
  3. **改整包模板**：模板里改字段，包长自动跟着变。

> 所有设置都会自动保存，杀掉 App 重开还在。换协议只需要在界面上改模板，不用重新打包 App。

## 三、固件端要发什么（速查）

**默认整包模板（11 字节）**：

```text
AA 55 {x} {y} {s1} {s2} {tx} {ty} {btn} 55 AA
```

| 偏移 | 字段 | 类型 | 说明 |
| --- | --- | --- | --- |
| 0-1 | `AA 55` | 包头 | 找帧头 |
| 2 | `x` | int8 | 摇杆 X，wire 上 = `值 + 128` |
| 3 | `y` | int8 | 摇杆 Y，同上 |
| 4 | `s1` | uint8 | 滑条 A，0 ~ 100 |
| 5 | `s2` | uint8 | 滑条 B，0 ~ 100 |
| 6 | `tx` | int8 | 搓动 X，`值 + 128`，128 = 没搓 |
| 7 | `ty` | int8 | 搓动 Y，同上 |
| 8 | `btn` | uint8 | 位图，bit0~bit5 = k1~k6 |
| 9-10 | `55 AA` | 包尾 | |

C 解包：

```c
if (len != 11 || b[0] != 0xAA || b[1] != 0x55 || b[9] != 0x55 || b[10] != 0xAA) return;
int8_t  x = (int8_t)(b[2] - 128), y = (int8_t)(b[3] - 128);
uint8_t s1 = b[4], s2 = b[5];
int8_t  tx = (int8_t)(b[6] - 128), ty = (int8_t)(b[7] - 128);
uint8_t btn = b[8];
```

**独立指令默认值**：摇杆 `AA 55 {x} {y} 55 AA`、滑条 `AA 55 {v} 55 AA`、搓动 `AA 55 {tx} {ty} 55 AA`、停止 `S`。

完整字段表、省字节写法和更多示例见仓库根 README 的「使用说明」一节。

## 四、这一版改了什么

- 页内底部恢复 **滑条 A / B**（0 ~ 100），整包对应 `{s1}` / `{s2}`。
- 右手搓动独立成 `tx` / `ty` 通道，不再和滑条抢通道，反向搓是负数。
- 搓动读数只在全屏顶部工具栏显示，页内不占地方。
- 整包默认模板升到 **11 字节**，包长跟着模板走。
- 独立指令新增 `touch`（默认 `{tx},{ty}`）。
- 设置自动保存覆盖发送模式与所有开关项。
- 修了 Pub 缓存在 C 盘、工程在 D 盘时 Kotlin 增量编译直接报错导致打不出包的问题。

---

## 五、已知限制

- 只支持 BLE（不支持经典蓝牙 SPP），同时只连一台设备。
- 波形只认 VOFA+ JustFloat，不支持 FireWater 文本协议。
- 没有前台服务，长时间切后台或锁屏可能被系统杀掉导致断连。
- 单包不会自动分包，超过 `MTU - 3` 会直接报错提示，避免破坏设备协议。
- 使用 debug 签名，仅供调试分发，上架应用商店需要自己换 keystore 重新签名。
